# LG U+ 리디자인 포트폴리오 (비공식)

HTML/CSS/JavaScript로 제작한 PC / 모바일 분리형 통신사 웹 퍼블리싱 시연 프로젝트입니다.

## 구조
- `index.html`: PC/모바일 선택 진입
- `pc/`: PC 전용 5개 HTML 페이지
- `mobile/`: 모바일 전용 5개 HTML 페이지
- `assets/style.css`: 공통 스타일 및 PC/모바일별 레이아웃
- `assets/main.js`: 배너, 메뉴, 검색어 페이지 이동, 필터, FAQ 동작

## 실행
파일을 압축 해제하고 `index.html`을 브라우저에서 열거나 GitHub Pages에 저장소 루트 전체를 업로드하세요.

## GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
주소 예시: `https://사용자명.github.io/저장소명/`

## 주의
LG유플러스 공식 사이트가 아닌 비공식 개인 포트폴리오입니다. 가격과 혜택 등은 시연용 예시입니다. Google Fonts 로딩에는 인터넷 연결이 필요합니다.
